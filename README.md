# ⚙️ PLC Programmering med Arduino Uno

## 🎯 Formål med opgavesamlingen
- at kunne bruge en Arduino Uno og OpenPLC til at lave et PLC program med Ladder Diagrams.

## 🛠️ Teknologier, som du lærer i denne opgavesamling
- PLC programmering: Ladder Diagram
- Simpel Arduino opstilling med kontakt, LED-pærer, modstand

## 🧠 Krav til forudgående viden
- Programmering (S): Ingen
- Webudvikling (W): Ingen
- Teknik (T): Ingen
- Arduino: Ingen
